# 座位图设计器验收标准

给客户/测试人员使用，按场景操作，逐项打勾。

---

## 1. 登录首页

### 1.1 看场馆列表
**操作：** 打开系统首页。  
**预期：** 左侧显示场馆列表，能看到场馆名称。  
**通过标准：**
- [ ] 场馆列表正常加载，无白屏。
- [ ] 列表为空时显示空白，不报错。

### 1.2 切换场馆
**操作：** 点击左侧任意场馆卡片。  
**预期：** 右侧画布加载该场馆座位图。  
**通过标准：**
- [ ] 点击后卡片高亮。
- [ ] 右侧显示对应场馆名称。
- [ ] 座位图正常渲染，能看到分区/排/座位。

---

## 2. 新增场馆

### 2.1 新建空白场馆
**操作：** 点击左侧"新增场馆"按钮。  
**预期：** 右侧变成空白画布，可开始绘制。  
**通过标准：**
- [ ] 按钮显示选中状态。
- [ ] 列表中其他场馆取消高亮。
- [ ] 右侧画布清空，无残留图形。
- [ ] 顶部名称显示为"未命名座位图"或默认名称。

---

## 3. 绘制座位图

### 3.1 画分区
**操作：** 左侧工具栏选择"分区"工具，在画布上拖拽绘制。  
**预期：** 画布上出现闭合分区。  
**通过标准：**
- [ ] 分区边框可见。
- [ ] 分区可被选中和移动。

### 3.2 画排/座位
**操作：** 选择"排"或"座位"工具，在分区内绘制。  
**预期：** 出现一排座位或单个座位。  
**通过标准：**
- [ ] 座位圆点可见。
- [ ] 座位数量与绘制一致。
- [ ] 放大后能看到座位标签。

### 3.3 设置分类颜色
**操作：** 右侧点击"管理分类"，新增/修改分类颜色。  
**预期：** 分类颜色应用到座位。  
**通过标准：**
- [ ] 分类列表能正常打开。
- [ ] 新增分类后，分类显示在列表中。
- [ ] 修改颜色后，对应分类的座位颜色同步变化。

---

## 4. 编辑属性

### 4.1 改场馆名称
**操作：** 右侧概览面板点击场馆名称旁的"铅笔"图标，输入新名称，按回车。  
**预期：** 顶部名称同步更新。  
**通过标准：**
- [ ] 点击后出现输入框。
- [ ] 输入新名称后顶部名称立即变化。
- [ ] 失焦或按回车后输入框关闭。

### 4.2 改分区名称
**操作：** 单击选中分区，右侧输入"分区名称"。  
**预期：** 分区名称更新。  
**通过标准：**
- [ ] 选中分区后右侧显示分区属性。
- [ ] 修改名称后保存，再次加载名称不丢失。

### 4.3 改座位分类
**操作：** 单击选中单个座位，右侧选择分类。  
**预期：** 座位颜色变化。  
**通过标准：**
- [ ] 座位分类修改后颜色立即变化。
- [ ] 保存后再次加载分类正确。

---

## 5. 保存与加载

### 5.1 保存场馆
**操作：** 点击顶部"保存"按钮。  
**预期：** 提示保存成功。  
**通过标准：**
- [ ] 点击后弹出"保存成功"提示。
- [ ] 刷新页面后，刚才绘制的内容还在。
- [ ] 场馆名称修改后保存，刷新后名称正确。

### 5.2 加载已有场馆
**操作：** 切换到一个已保存的场馆。  
**预期：** 座位图完整加载。  
**通过标准：**
- [ ] 分区、排、座位都显示。
- [ ] 分类颜色正确。
- [ ] 座位数量和保存时一致。

---

## 6. 框选与多选

### 6.1 框选分区
**操作：** 按住鼠标左键在画布上拖拽，框住多个分区。  
**预期：** 被框住的分区被选中。  
**通过标准：**
- [ ] 框选过程中不报错。
- [ ] 松开鼠标后，右侧显示对应属性或批量编辑。
- [ ] 被选中的分区有明显高亮。

### 6.2 多选排/座位
**操作：** 框选一个区域内的排或座位。  
**预期：** 多个对象被选中。  
**通过标准：**
- [ ] 框选操作流畅。
- [ ] 右侧面板正确切换。
- [ ] 不触发任何报错弹窗。

---

## 7. 缩放与平移

### 7.1 放大缩小
**操作：** 鼠标滚轮向前/向后滚动。  
**预期：** 画布放大/缩小。  
**通过标准：**
- [ ] 滚动时画布平滑缩放。
- [ ] 放大到合适倍数后座位圆点显示。
- [ ] 缩小时能看到整体布局。

### 7.2 平移画布
**操作：** 按住空白处拖拽。  
**预期：** 画布随鼠标移动。  
**通过标准：**
- [ ] 拖拽时画布跟随移动。
- [ ] 平移后对象位置正确。

---

## 8. 导入导出

### 8.1 导出场馆数据
**操作：** 点击顶部"导出"按钮。  
**预期：** 下载 JSON 文件。  
**通过标准：**
- [ ] 点击后浏览器开始下载。
- [ ] 下载的文件能用文本编辑器打开。

### 8.2 导入场馆数据
**操作：** 点击顶部"导入"按钮，选择刚才导出的 JSON。  
**预期：** 画布显示导入的场馆。  
**通过标准：**
- [ ] 导入后座位图正确渲染。
- [ ] 导入的分类、名称和导出时一致。

---

## 9. 异常场景

### 9.1 网络错误
**操作：** 断开网络后刷新页面或保存。  
**预期：** 给出明确提示。  
**通过标准：**
- [ ] 加载失败提示"数据加载失败"。
- [ ] 保存失败提示"保存失败"。
- [ ] 页面不白屏。

### 9.2 空场馆
**操作：** 新建场馆后不绘制任何内容，直接保存。  
**预期：** 保存成功。  
**通过标准：**
- [ ] 空场馆能保存。
- [ ] 再次加载后仍是空白画布。

---

## 10. 验收不通过红线

以下任一情况出现，视为验收不通过：

1. [ ] 框选、拖拽、切换场馆时页面报错或白屏。
2. [ ] 座位数据保存后丢失或显示位置错乱。
3. [ ] 场馆名称、分类颜色保存后再次加载不对。
4. [ ] 5000 个座位下操作明显卡顿，无法正常使用。
5. [ ] 任何操作导致浏览器控制台出现红色报错。

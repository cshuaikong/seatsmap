设计端 Vue 对接文档（ESM 组件） ​

适用于 Vue3 / Vite / webpack 项目：npm install 安装组件包，import 引入。静态页面 / jQuery 项目请走 JS 对接文档。

获取产物 ​

设计器以打包好的组件交付。需联系开发者获取组件（交付包 seatmap-designer-pkg.tar.gz）。

默认安装方式（解压到项目根目录后安装）：

bash
# 1. 把交付包解压到项目根目录（得到 seatmap-designer-pkg/）
tar -xzf seatmap-designer-pkg.tar.gz

# 2. 安装到项目依赖
npm install ./seatmap-designer-pkg

产物说明（Vue 对接）：本文档对接的是 ES 版组件 seatmap-designer.es.js + seatmap-designer.css（leafer 全量内置，仅 vue 走外部依赖）。 JS 对接用的是另一个产物 seatmap-designer.umd.js（单文件全内置 + CSS 内联），见 JS 对接文档。

前置条件 ​

  • 宿主项目需为 Vue 3（Vue 2 项目见下文适配说明）。
  • 宿主需自备 vue@^3：ES 构建把 vue 列为外部依赖、不重复打包；项目里 npm install vue@^3 即可。
  • 无需安装其他运行时依赖：leafer 及其插件已全量打进产物，不要求宿主安装。

快速开始 ​

vue
<script setup>
import { ref } from 'vue'
import SeatMapDesigner from 'seatmap-designer'
import 'seatmap-designer/style.css'

const designerRef = ref(null)

// 保存：宿主导函数，返回 true 才算成功（真正把数据写到后端的通道）
// 由组件中保存按钮 / Ctrl+S / save() 方法触发；宿主 POST 成功、return true 前即可提示（宿主比组件先知道成功）
async function onSave(payload) {
  const res = await myApi.saveVenue(payload)
  if (res.code === 0) {
    refreshVenueList()        // 保存成功：刷新场馆列表
    message.success('已保存')  // 或 toast 提示
  }
  return res.code === 0       // 只有 true 才算保存成功（失败返回 false，组件保留脏标记）
}

// 图片上传：底图 / 水印 logo 共用；接收 File，上传后返回图片完整 URL（http(s)://）
async function onUpload(file) {
  const fd = new FormData()
  fd.append('file', file)
  const res = await fetch('/upload', { method: 'POST', body: fd })
  const body = await res.json()
  if (body.code !== 0) throw new Error(body.msg || '上传失败')
  return body.data.url        // 必须返回完整 URL，否则设计器报错
}
</script>

<template>
  <SeatMapDesigner
    ref="designerRef"
    :save-handler="onSave"
    :upload-handler="onUpload"
  />
</template>

保存成功与否由 saveHandler 返回值决定；图片上传由 uploadHandler 处理（不配置则上传报错）。 组件默认填满挂载容器（height:100%）；容器无高度时兜底 480px。要全屏请在挂载容器上给高度（如外层 <div style="height:100vh">）。

加载场馆数据 ​

方式一：prop 传入（响应式，组件自动喂）

vue
<script setup>
const venue = ref(null)
const seatlist = ref(null)
// 取数后赋值即可；venue 先到、seatlist 后到也支持（组件自动并入）
async function load() {
  const data = await myApi.loadVenue(venueId)
  venue.value = data.venue
  seatlist.value = data.seatlist
}
</script>

<template>
  <SeatMapDesigner
    ref="designerRef"
    :venue="venue"
    :seatlist="seatlist"
    :save-handler="onSave"
  />
</template>

方式二：命令式 setData（ref 方法）

js
const { venue, seatlist } = await myApi.loadVenue(venueId)
designerRef.value.setData(venue, seatlist)
// 大场馆分段：
// designerRef.value.setData(venue)
// designerRef.value.mergeSeats(seatlist)

两种方式等价、可混用（同一数据别两路同时喂）：prop 变化会自动重新加载；setData() 是主动调用。

Props ​

Prop类型说明
saveHandlerFunction宿主导函数 fn(payload)=>Promise<true>（唯一保存通道，与 setSaveHandler 方法等价）
uploadHandlerFunction图片上传器 fn(File)=>Promise<URL>（底图/水印 logo 共用；不配则上传报错）
optionsObject实例化自定义参数：defaultCategories / seatDefaults / limits / zoom / ui / tools
themeString初始主题 `'light'
venueObject场馆主体（后端原始格式，含 sections 骨架）；变化时自动 setData（与 setData() 方法等价，二者可混用）
seatlistArray座位列表（可后到）；变化时自动 mergeSeats（渐进加载：venue 先到、seatlist 后到）

Emits ​

事件参数说明
ready—首次渲染完成
change—数据变更（含载入）
errorerr初始化/渲染/接口错误
venuebackendId场馆身份确定或变化（载入/新建/导入/首次保存建档）；本地场馆为 null
dirtyv脏状态直报：编辑 true、保存/载入 false；路由切换拦截存个布尔值即可

实例方法（ref 调用） ​

方法说明
setData(venue, seatlist?)喂数据（后端原始格式；seatlist 可省，只上轮廓），主路径
mergeSeats(seatlist)分段喂座位（不动视图）
save()触发保存（走 saveHandler）
setSaveHandler(fn) / setImageUploader(fn)注入宿主导函数 / 图片上传器
getSavePayload()取当前保存 payload
exportJSON() / importJSON(json)设计器内部格式导入导出
fit()视图适配全图
newVenue(init)新建空白场馆；init：string=名字 或 { id, name, ...extra }
setLoadPhase(p)驱动内置加载 UI（'venue' / 'seats' / ''）
getState(){ venueId, name, sections, seats, saving, dirty }
setOptions(partial) / setTheme(t)运行时改配置 / 切换主题
exportPDF(opts) / exportSVG(opts) / exportPNG(opts)导出场馆大图为 PDF / SVG / 超高清 PNG，触发浏览器下载
vue
<script setup>
function load() { designerRef.value?.setData(venue, seatlist) }
</script>
<template>
  <SeatMapDesigner ref="designerRef" />
</template>

Vue 2 项目能否适配 ​

不能直接作为 Vue 组件使用：seatmap-designer.es.js 是 Vue 3 组件（vue 为外部依赖），宿主必须是 Vue 3。

可用的接入方式：改用 UMD 单文件（seatmap-designer.umd.js，已内置 vue 3、不依赖宿主 Vue 版本），在 Vue 2 项目里命令式挂载——具体步骤、代码示例、事件订阅与卸载，见 JS 对接文档。

代价：Vue 2 下走命令式接入，无法使用 Vue 组件的 props / emits。

注意事项 ​

  • 同一页面只挂载一个设计器实例（内部 store 为模块级单例）。
  • 组件默认填满挂载容器（height:100%）；容器无高度时兜底 480px——要全屏请在挂载容器上给高度。
  • 组件随 v-if 自动卸载；不需要手动 destroy()。
  • 样式已加 .seatmap-designer 前缀隔离，不会污染宿主页面。
  • options 须在组件创建前生效（zoom 范围在建画布时读取）；运行时改 ui/zoom 立即生效，defaultCategories 只影响之后的 newVenue。

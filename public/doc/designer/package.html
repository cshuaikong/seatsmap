设计端交付包说明（组件包内容） ​

设计器以打包好的组件交付（不提供源码），交付物为压缩包 seatmap-designer-pkg.tar.gz，组件名 seatmap-designer。解压后得到 seatmap-designer-pkg/ 目录。

包内容清单 ​

文件作用对接方式
seatmap-designer.umd.jsUMD 单文件：vue / leafer / css 全内置 + CSS 注入JS 对接（静态页 / jQuery / Vue2 命令式）
seatmap-designer.es.jsES 组件：leafer 内置，仅 vue 走外部依赖Vue 对接（Vue3 / Vite / webpack）
seatmap-designer.css组件样式（ES 版需显式引入；UMD 已内联）Vue 对接
package.jsonnpm 包元信息（main / module / exports / style）安装 / 引用入口
index.es-*.js 等 chunkES 入口的运行时依赖（核心 / 截图 / 净化等懒加载模块）随入口自动加载

关于 chunk 文件 ​

index.es-*、html2canvas-*、purify.es-*、rolldown-runtime-*、typeof-* 这些带 hash 的文件，是 seatmap-designer.es.js 的运行时依赖：

  • html2canvas-* —— 导出 PNG/PDF 截图
  • purify.es-* —— DOMPurify，导出 SVG 时净化 HTML
  • rolldown-runtime-* / typeof-* —— bundler 运行时与工具函数
  • index.es-* —— ES 入口拆出的核心 chunk

它们由入口按需懒加载，不要单独引用、也不要删。解压后请保留整个目录，不要只拷单个入口文件（否则导出 / 截图功能会因懒加载 chunk 缺失而失败）。

UMD 与 ES 怎么选 ​

场景用哪个
静态页面 / jQuery / 无构建工具seatmap-designer.umd.js（全内置，<script> 引入即用）
Vue 2 项目（想用组件式 props/emits 不可行）用 UMD 命令式挂载（见 JS 对接）
Vue 3 / Vite / webpackseatmap-designer.es.js + seatmap-designer.css

包内文档 ​

交付包内自带两份说明，用户解包后 / 装进 node_modules 后可直接读到，也便于 AI 读取快速对接：

  • README.md —— 组件定位、包内容、UMD/ES 两种快速开始、关键约定
  • api-contract.md —— 构造参数 / 实例方法 / 事件 / Props / Emits / 保存协议 的完整契约

使用方式 ​

  • JS 对接：tar -xzf seatmap-designer-pkg.tar.gz → <script src="/libs/seatmap-designer.umd.js">，详见 JS 对接文档。
  • Vue 对接：tar -xzf ... → npm install ./seatmap-designer-pkg，详见 Vue 对接文档。

产物无需 Node 环境、无需安装其他依赖（UMD 全内置；ES 仅需宿主自备 vue@^3）。样式已加 .seatmap-designer 前缀隔离，不会污染宿主页面。

设计端操作说明 ​

座位图设计器：在画布上绘制场馆分区、排与座位，配置类别 / 标签 / 水印，出票预览，并保存场馆数据。

配图为本仓库开发环境实机截图（docs/scripts/capture.mjs 可重新生成）。截图中场馆为演示数据，实际使用请加载你们的真实场馆。

一、界面布局 ​

设计器自上而下、自左而右分五区：顶栏、工具栏、画布、侧栏、状态栏。

区域作用
顶栏场馆名、预览、主题切换、保存、撤销/重做、吸附开关、对齐/分布/翻转菜单、复制/粘贴/副本、删除
工具栏绘制与编辑工具（详见下文）
画布场馆绘制区域（Leafer canvas），支持缩放 / 平移 / 辅助线
侧栏当前选中对象（分区 / 排 / 座位 / 底图 / 场馆）的属性编辑面板
状态栏实时显示缩放比例、分区数、座位数、选中数

二、工作流程 ​

  1. 新建 / 加载场馆：顶栏左侧场馆列表新建或选择；也可由宿主调用 newVenue() / setData(venue, seatlist) 加载。
  2. 上传底图（可选）：工具栏「底图」工具或侧栏上传，作为描图参照（可调透明度 / 缩放 / 锁定）。
  3. 绘制分区：矩形分区（U）、圆形/椭圆分区（C）或自由多边形分区（P），画出场馆分区轮廓。
  4. 绘制座位：单行座位（R）逐排绘制，或多行座位（G）一次生成多排；进入分区后可精细调整。
  5. 配置类别与标签：类别管理设置价格区颜色；批量编号为排 / 座位编号；分区可配水印。
  6. 保存：Ctrl+S 或顶栏保存按钮。首次保存走全量，之后只发增量（见后端接口文档）。

套索工具 ​

框选的用途 / 功能：框选是「先选后操作」的批量编辑入口——一次框选（矩形框选或套索）选中一组排 / 分区（座位编辑模式下为座位），随后可对整组统一移动、旋转、对齐 / 分布、删除（多选后顶栏「对齐 / 分布 / 翻转」菜单生效，按 Delete 批量删除），避免逐个操作。

套索适用于斜排 / 过道中段等矩形框选难以选中的座位。按住鼠标画出包围圈，笔画穿过的排/分区即被选中；Shift 加选，Esc 取消。

矩形框选 vs 套索：矩形框选只能扫过「规则矩形区域」内的对象（规整排布够用）；套索用自由笔画穿过目标，对斜排、过道拐角、弧形分区内的对象也能精确选中。两者选中的结果一致——都是得到一组可统一操作的对象。

节点编辑 ​

选中分区后切到节点工具，拖动轮廓顶点可整体变形，拖动边线中点调整弧形分区的弧度；矩形分区支持拖角点等比缩放、拖边线单边缩放、拖角调圆角；圆形/椭圆分区显示 4 个方向手柄——拖东西手柄调横向半径、拖南北手柄调纵向半径（双半径独立调整，圆心不动）。

四、画布操作 ​

  • 缩放：Ctrl/Cmd + 滚轮；也可用右下角缩放控件（+ / − 按钮、范围 0.02~25）。
  • 平移：按住空格或鼠标中键拖拽；H 工具；缩放控件的四向箭头与中心摇杆。
  • 吸附：顶栏「吸附」开关。拖动分区/底图时对齐参考线（分区边/中心线）；Alt 临时禁用，Shift 锁 45°。
  • 显示座位条：顶栏开关，控制座位编号条的显隐。
  • 对齐 / 分布 / 翻转：顶栏菜单——左中右对齐、上中下对齐、水平/垂直均匀分布、校正（straighten）、水平/垂直翻转，多选后使用。
  • 状态栏：实时显示缩放比例、分区数、座位数、选中数。

五、编辑操作 ​

分区对象模式（默认） ​

  • 单击选中，Shift 加选，画布拖框框选，Ctrl+A 全选。
  • 拖动移动（带吸附）；拖旋转手柄旋转；Delete 删除（弹确认，可撤销）。
  • 双击分区进入座位编辑模式；双击空白或按 Esc 退出。

座位编辑模式 ​

进入后画布顶部出现「✏ 正在编辑分区：××」面包屑，侧栏切到该分区的排/座位属性。框选座位可移动/旋转；排长手柄可拖拽增减座位（row-resize）；Esc 或「退出分区」按钮返回对象模式。

框选 vs 套索 ​

  • 框选：矩形扫过即选（适用于规整排布）。
  • 套索：自由笔画穿过命中（适用于斜排/过道中段）。

正式分区优先于散座被选中。

七、侧栏属性编辑 ​

分区属性 ​

选中分区后侧栏显示：座位数、角弧度（圆角矩形）、分区默认类别、标签样式（文本 / 可见 / 字号 / 旋转 / XY 偏移）、赞助商水印（文本 / Logo 图 / 颜色 / 宽度 / 透明度 / 字号 / 行距 / 旋转 / XY）。

排属性 ​

进入分区后选中排：座位数、旋转、弧度、排距（多排）、座位间距、对齐（左中右）、排标签（单排文本 / 首尾端位置）、座位编号摘要。

座位属性 ​

选中座位：编号、类型（普通 / 椅子 / 凳子 / 长凳）、状态（可售 / 预留 / 已售 / 禁用）。

场馆属性 ​

场馆改名、类别数/座位数统计、数据校验（重复 / 未标记 / 未分类座位）、常驻图例。

八、类别与批量编号 ​

类别管理 ​

配置座位类别（价格区）：key、color（色板 + 自定义）、label、price。类别颜色即座位渲染颜色，价格供选座端合计。使用中的类别删除需行内确认。

批量编号 ​

对排 / 分区 / 座位批量编号：

  • 排/分区编号格式：字母（A,B,C…）/ 数字（1,2,3…）/ 罗马数字（I,II,III…）
  • 座位额外格式：奇偶（odd/even）、奇偶交替（oddEven）、镜像（mirror）、小写字母（alphaLower）
  • 起始值、正向 / 反向、清除
  • 规则：每排独立从起始值编号

十、只读模式 ​

后端场馆标记 readonly: 1 时，设计器进入只读：顶栏隐藏保存按钮、忽略 Ctrl+S、显示「只读」徽标，所有编辑操作禁用。用于运营预览/审核场景。

十一、大型场馆 ​

设计器支持 4 万级座位的绘制与编辑。大场馆加载可分段喂数据（轮廓先上屏、座位后并入）以加快首屏；日常保存只发座位增量（KB 级），详见后端接口文档。
